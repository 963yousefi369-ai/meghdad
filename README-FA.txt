راهنمای سریع دعوت‌نامه
======================

این پروژه کاملاً فرانت‌اند و بدون بک‌اند است.
برای تغییر اطلاعات، فقط فایل config.js را باز کن و متن‌های داخل کوتیشن را عوض کن.

تاریخ شمارنده:
eventDate باید به فرمت ISO باشد؛ مثال تهران:
2026-10-09T18:30:00+03:30

موسیقی:
یک فایل MP3 با نام music.mp3 داخل پوشه assets بگذار.
پخش موسیقی طبق قوانین مرورگر فقط بعد از لمس دکمه انجام می‌شود.

دیپلوی:
- Netlify: کل پوشه را در Netlify Drop رها کن.
- GitHub Pages: محتویات پوشه را در ریشه repository بگذار.
- Cloudflare Pages: پوشه را به‌عنوان static site منتشر کن.
هیچ build command لازم نیست.

پیشنهاد تست:
قبل از انتشار، index.html را روی موبایل با یک local server باز کن.
مثال: python3 -m http.server 8080

فایل‌های اصلی:
index.html  ساختار صفحه
styles.css  ظاهر و انیمیشن‌ها
app.js      اسکرول، شمارنده و تعاملات
config.js   نام‌ها، تاریخ، آدرس و لینک نقشه
assets/     تصاویر، فونت و موسیقی
